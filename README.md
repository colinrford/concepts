# `lam.concepts`
Experimental concepts for use in [LAM](https://www.github.com/colinrford/lam).

this is public but very much a work in progress. These are probably not the 
concepts you are looking for (yet!).

### A brief aside on (non-)usage of LLMs (namely Claude)
I have not used Claude or any other LLMs in developing the `c++` concepts found 
here in `lam.concepts`. I have not needed to. They are also far from perfect.

I have used Claude to help with Cmake and Conan things.
